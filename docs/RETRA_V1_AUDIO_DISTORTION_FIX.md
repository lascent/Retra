# Retra v1.0.0 — Background Music Distortion Fix

This build keeps the mGBA game-audio mixer unchanged and hardens only Retra's final conversion into the Android output stream.

## What changed

- Replaced the extra mGBA utility sinc-resampler stage used by Retra's Android bridge with a Retra-local 16-tap, 1024-phase band-limited resampler.
- Normalizes every fractional-delay phase so normal sample-rate conversion does not unintentionally change gain.
- Uses an anti-alias cutoff when the GBA source stream is converted down to the Android output rate.
- Explicitly saturates every converted PCM sample to signed 16-bit range before writing it to AudioTrack, preventing overflow/wrap-style distortion at peaks.
- Bypasses resampling completely when source and destination rates already match, preserving samples exactly.
- Preserves the existing dedicated AudioTrack writer, blocking writes, prebuffering, adaptive underrun handling, turbo/slow-motion behavior, and the D-pad 9.8–10 improvements.

## Design goal

Do not EQ, enhance, spatialize, or otherwise recolor the game music. Retra should reproduce the PCM generated by mGBA as faithfully as the Android device output clock allows.
