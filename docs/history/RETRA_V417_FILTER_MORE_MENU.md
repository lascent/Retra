# Retra v4.17 — Filter Three-Dot Menu

- Made the three-dot button in the ROM Filter / Add to categories sheet functional.
- Added **Set as default** to save the currently selected categories as the default assignment for newly imported ROMs.
- Added **Reset** to restore the current sheet selection to the saved default; if no default exists, it clears the selection.
- New ROMs imported through both the Android picker and browser/file fallback inherit the saved default categories.
- Deleting a category also removes it from the saved default set.
- The options menu closes when tapping outside it or closing the filter sheet.
