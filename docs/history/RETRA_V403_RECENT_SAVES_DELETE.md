# Retra v4.03 — Recent Saves + Hold to Delete

## ROM Library → Recent saves
- The ROM detail page now reads the real native save-state files for that ROM.
- Quick Save and Slot 1–10 appear automatically when they exist.
- Saves are sorted by newest first and show their real save date/time.
- Tapping the load icon launches that ROM and restores the selected save state.
- The list refreshes automatically after a save state is created or deleted.
- The Statistics save-state count refreshes after deletion.

## Delete save states
- Press and hold a save entry in ROM Library → Recent saves to open a delete confirmation.
- Right-click also opens the delete confirmation for desktop testing.
- Deletion removes both the state file and its thumbnail.
- Press and hold a slot in the native in-game Save/Load screen to delete it there too.
- Empty slots cannot be deleted.

## Persistence / separation
- Save states remain isolated per ROM ID.
- Deleting a state for one ROM does not affect any other ROM.
