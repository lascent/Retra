# Retra v3.92 — Controller Opacity

## Video setting
Added **Settings > Video > Controller Opacity** directly above **Screen size**.

- Range: **25%–100%**
- Default: **100%**
- Updates live while the slider moves
- Persists between app launches
- Applies to the native gameplay controls: D-pad, A/B, L/R, Start/Select, Menu, and utility buttons
- The Screen Editor previews the selected opacity
- Editor-only controls such as Back, Add Controller, selection UI, and resize handles remain fully visible

Portrait remains 100% default controller size and landscape remains 125% default controller size. The v3.89 centered D-pad arrows are preserved.
