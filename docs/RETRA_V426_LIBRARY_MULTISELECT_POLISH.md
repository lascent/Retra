# Retra v4.26 — Library Multi-Select Polish

- Centers the three multi-select actions across the full bottom action bar.
- Slightly enlarges Categories, Favourite, and More icons/touch targets.
- Favourite/Unfavourite now applies immediately and exits selection mode automatically.
- Removes **Delete Game Data** from the bulk-selection More menu. Single-ROM game-data deletion remains available from the individual ROM actions.
- Optimizes additional ROM selection taps by updating only the card that changed instead of walking the entire rendered Library grid.
- Disables redundant long-press timers once selection mode is active and removes expensive mobile blur from multi-select overlays for lower input latency in Android WebView.
