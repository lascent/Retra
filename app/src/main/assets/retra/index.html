Privacy Policy

Retra Privacy Policy

Effective for Retra v1.0.0

Local game data. Retra stores your library metadata, settings, save files, save states, cheats, controller layouts, artwork preferences, and play statistics on your device. Retra does not include ROMs or copyrighted game software.

Network features. Internet access is used only for features you choose to use, such as automatic artwork lookup, optional Google Drive synchronization, and Wi-Fi Remote Link. Bluetooth access is used only for Bluetooth Remote Link.

Google Drive. If you enable Drive sync and select an account, Retra uses the authorization granted by you to synchronize supported Retra data with your own Drive storage. Drive sync can be disabled at any time.

No advertising or analytics SDK. This build does not include an advertising SDK or a third-party analytics SDK.

Permissions. Retra requests device or network permissions only when needed for enabled features. You can revoke Android permissions from system settings.

Data deletion. Removing a game from the Library is non-destructive by design. Use Retra's explicit Delete Game Data action when you want associated local game data removed.

Policy updates. If Retra's data practices change, this policy should be updated before publishing the changed build.
